Indexed vectors and proofs

A vector’s length is part of its type. A Fin<n> index selects one of its n positions.

public definition Vec<TElement, length> Copy<TElement, ghost Nat length>(
    Vec<TElement, length> values) => values;

public lemma SameValue() ensures PreservedValue() == 42
    proof { assert PreservedValue() == 42; }

Raw strings and checked formatting

A multiline raw string dedents against its closing delimiter. Format.Write appends into a fixed-capacity builder.

public TextBuilder<36> FormatPacket(Nat id, bool ok) {
    let TextBuilder<36> builder = EmptyBuilder();
    let TextBuilder<36> hdr = Format.Write(ref builder, $"hdr={HeaderTag()} ");
    return Format.Write(ref hdr, $"id=0x{id:x4} ok={ok}");
}

Records and properties

Read a computed property or construct an updated record with with { … }.

public record Counter(Nat Value, Nat Limit) {
    public bool AtLimit => this.Value >= this.Limit;
}
public definition Counter Advance(Counter counter, Nat step) =>
    if (counter.AtLimit) counter else counter with { Value = counter.Value + step };

Compile-time constants

A const parameter supplies a compile-time value. A regular parameter can carry runtime data.

public Nat Scale(const Nat gain, Nat sample) {
    const Nat multiplier = Square(gain);
    return multiplier * sample;
}

{
    InitBounds(10, out var low, out var high);

Selective invariant lifting

Example ▾

The open block lifts only the named invariant during an update. Vela requires proof of the invariant at block exit. Contract rules ↗ 

public RangeWindow RebalanceWindow()
{
    var window = RangeWindow(2, 5);
    open (ref window) lifts Ordered
    {
        window.Low = 4;
        window.High = 9;
    }
    return window;
}

Bounded loops

Example ▾

A half-open low..high range bounds a foreach loop. A while loop states its invariant and decreasing measure. Loop rules ↗ 

public usize CountUpTo(usize limit)
    requires limit <= 8usize
    ensures result == limit
{
    var i = 0usize;
    while (i < limit)
        invariant i <= limit
        decreases limit - i
    {
        i += 1usize;
    }
    return i;
}

What the playground checks

The browser translates pure modules and previews supported mathematical inputs. Run python tools/run.py vela-playground to use the local mathematical elaborator. Use the Rocq replay commands ↗ to check emitted proofs.

Surface parser Menhir recognizes syntax before name resolution. Editor tools Formatting, style checks, and navigation for pure modules. Mathematical elaborator Emit Gallina for supported types, functions, and proofs. Kernel replay Check the emitted terms and audit their assumptions.
